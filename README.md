# مرسال

تطبيق تواصل اجتماعي عربي (RTL) بمقاس الجوال: محادثات فورية بحالات الإرسال والاستلام والقراءة،
حالات شخصية تختفي بعد ٢٤ ساعة، مجموعات بإدارة مشرفين، مكالمات صوتية ومرئية، مشاركة ملفات
ومواقع وتسجيلات صوتية، مع تفعيل خيارات الخصوصية والأمان والتخزين والنسخ الاحتياطي.

التسجيل برقم الهاتف فقط (رمز تحقق)، وباسم اختياري. التطبيق لا يحتوي على بيانات أو حسابات تجريبية.

## التشغيل (بيئة التطوير)

```bash
docker compose -f docker-compose.base44.yml up -d --build
```

- الواجهة: `http://localhost:3000` (المنفذ الذي يعرضه المعاينة)
- الـ API والتوثيق: `http://localhost:8000/docs`
- في وضع المعاينة يظهر رمز التحقق على الشاشة (لا توجد بوابة SMS)؛ لتشغيل SMS الحقيقي أضف
  `TWILIO_ACCOUNT_SID` و`TWILIO_AUTH_TOKEN` و`TWILIO_FROM_NUMBER` من صفحة الأسرار.

الخدمات الثلاث: `db` (PostgreSQL 16) ثم `api` (uvicorn --reload) ثم `web` (Vite dev server)،
وكلها تقرأ الكود من المستودع مباشرة عبر bind mount، فأي تعديل يظهر دون إعادة بناء.

## البنية

- `frontend/` React 18 + Vite + Tailwind — واجهة عربية RTL بعرض أقصى 480px.
- `backend/` FastAPI + SQLAlchemy + PostgreSQL + WebSocket.
- `docker-compose.base44.yml` بيئة قاعدة البيانات والـ API والواجهة (وخدمة اختبارات اختيارية).

### كيف يعمل الكود

1. **طلب واحد لأصل واحد**: المتصفح لا يعرف عنوان الـ API. Vite يمرّر `/api` و`/ws` إلى
   `http://api:8000` (انظر `frontend/vite.config.js`)، لذلك تُستخدم المسارات النسبية `/api/...` فقط.
2. **الجلسة**: `POST /api/auth/request-code` يُنشئ رمزًا مربوطًا بالهاتف (HMAC-SHA256، صلاحية ٥ دقائق)،
   ثم `POST /api/auth/verify` يعيد JWT (HS256، ٣٠ يومًا). الواجهة تحفظه في `localStorage` وترسله
   كـ `Authorization: Bearer`. في وضع المعاينة فقط يُعاد الرمز في الاستجابة (`dev_code`) لعرضه على الشاشة.
3. **البيانات**: الجداول تُنشأ عند الإقلاع عبر `Base.metadata.create_all` (لا يوجد Alembic)،
   والوسائط تُخزَّن في volume `media-data` على `/data/media` وتُقدَّم عبر `/api/media/{id}?token=...`
   مع تحقق من صلاحية الوصول.
4. **التحديثات الفورية**: WebSocket على `/ws` يحمل الرسائل و«يكتب الآن» وحضور المستخدمين وإشارات
   المكالمات (WebRTC، STUN عام) — الإشارات تمر عبر نفس الاتصال.

## الاختبارات

```bash
# اختبارات الخادم — وحدات + تكامل على قاعدة <db>_test منفصلة تُنشأ وتُفرَّغ تلقائيًا
docker compose -f docker-compose.base44.yml --profile test run --rm tests

# اختبارات الواجهة (دوال التنسيق وقفل التطبيق)
docker compose -f docker-compose.base44.yml exec -T web npm test

# فحص بناء الواجهة
docker compose -f docker-compose.base44.yml exec -T web npx vite build
```

تغطي اختبارات التكامل المسار الرئيسي: تسجيل برقم الهاتف → محادثة مباشرة → إرسال رسالة وقراءتها،
إضافة إلى الإعدادات والمجموعات ورفض الطلبات بلا جلسة.

## الميزات

- محادثات فردية ومجموعات، رسائل نصية ووسائط وملفات وتسجيلات صوتية ومواقع، حالات ✓ / ✓✓ / ✓✓ مقروءة.
- صفحات: المحادثات، الحالات، المكالمات، المجموعات، الإعدادات، الملف الشخصي، الخصوصية والأمان،
  الإشعارات، التخزين والنسخ الاحتياطي، وجهات الاتصال.
- خصوصية مطبقة خادميًا: الظهور، آخر ظهور، صورة الملف، من يراسلك، من يتصل بك، من يضيفك للمجموعات،
  إشعارات القراءة، الحظر، وقفل التطبيق برمز.
- تخزين: تفصيل استهلاك الوسائط، مسح التخزين المؤقت، نسخ احتياطي وتنزيله.
